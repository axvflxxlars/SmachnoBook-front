# SmachnoBook — фронтенд

Простий фронтенд на HTML, CSS і JavaScript для сайту з рецептами.
Сторінка завантажує список рецептів з API бекенду та дозволяє шукати
рецепти за назвою. Фронтенд працює на іншому порту, ніж бекенд, тому
для запитів потрібне налаштування CORS на сервері.

## Як запустити проєкт

1. Запустіть бекенд (інструкція в README бекенд-репозиторію). Він має
   працювати за адресою **http://127.0.0.1:8000**.
2. У папці цього репозиторію запустіть статичний сервер:

   ```bash
   python -m http.server 5500
   ```

3. Відкрийте у браузері **http://127.0.0.1:5500**.

| Частина  | Адреса                       |
| -------- | ---------------------------- |
| Фронтенд | http://127.0.0.1:5500        |
| Бекенд   | http://127.0.0.1:8000/api/v1 |

Адреса бекенду задана константою `API_URL` на початку `script.js`.
Якщо відкривати фронтенд за іншою адресою (наприклад,
`http://localhost:5500`), її потрібно додати до `CORS_ALLOWED_ORIGINS`
у налаштуваннях бекенду.
